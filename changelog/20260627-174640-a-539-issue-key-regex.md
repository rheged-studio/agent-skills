## Fixed

- **Deterministic issue-ID regex in `linear-sync` and cleanup-repo ([R-539](https://linear.app/rheged-studio/issue/R-539)).**
  Both skills left the `issueKeys`→regex to the model in prose ("join `issueKeys`
  with `|`"), which reproduces a precedence bug for multi-key teams:
  `["A","B"]` → `\bA|B-\d+\b`, i.e. `\bA` _or_ `B-\d+\b` — matching a bare `A` and
  missing `R-7`. The prose now specifies the **deterministic** construction the
  changelog bundle's `add-links.mjs` (`ISSUE_RE`) already implements and tests:
  escape each key's metacharacters, wrap the alternation in `(?:…)` when there is
  more than one key (`\b(?:A|B)-\d+\b`), and match nothing when no keys are
  configured. Each skill cross-references that canonical implementation so the rule
  can't drift. (A vendored shared `lib/issue-keys.mjs` consumed by every bundle —
  the review's longer-term ideal — stays deferred pending a cross-bundle vendor/
  drift-check mechanism; the bundles remain independently installable with no
  cross-bundle imports.) Bundled as `linear-sync@0.3.1` and `cleanup-repo@0.3.1`.
