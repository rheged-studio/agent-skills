## Fixed

- **`send-it` base-ref resolution honours `config.json` `baseBranch` ([R-532](https://linear.app/rheged-studio/issue/R-532)).**
  `resolveBaseRef` hardcoded the chain `BASE_REF → origin/main → main` and never
  read `baseBranch`, so a consumer whose trunk is `develop` (with
  `baseBranch: "develop"`) still diffed against `origin/main` — yielding the wrong
  commit range and bump signal in `derive-bump` / `check-skill-bumps`. The chain now
  slots the configured trunk in ahead of the fallback (`BASE_REF → origin/<baseBranch>
  → <baseBranch> → origin/main → main`); with `baseBranch: "main"` it collapses to
  the original list, so existing repos are unaffected. The candidate-list logic is
  factored into a pure `baseRefCandidates` with unit coverage. Bundled as
  `send-it@0.3.3`.
